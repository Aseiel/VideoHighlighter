# AMD GPUs go through DirectML, and `torch-directml` is deliberately NOT listed
# here. It pins an exact torch version, so pip satisfies it by *replacing* the
# installed torch, which silently removes Arc (+xpu) or CUDA (+cu128) support on
# any machine that had it. It is opt-in, user-installed, into its own virtualenv.
# (Also: there is no `torch-directml>=1.13`; releases are dated dev builds like
# 0.2.5.dev240914, so a normal version floor matches nothing.) See docs/AMD-GPU.md.
#
# ONNX Runtime's DirectML provider is the half of that story a build *can* ship:
# it declares no torch dependency, so it sits beside the CUDA torch above instead
# of replacing it, and it gives a DX12 card the heaviest stage (object detection)
# through an ONNX export. Windows-only wheels, hence the marker. Keep it the only
# onnxruntime here: `onnxruntime` and `onnxruntime-gpu` install the same package
# and would overwrite it.
