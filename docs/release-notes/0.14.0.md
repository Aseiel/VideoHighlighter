# VideoHighlighter 0.14.0

The theme of this release is seeing what the app sees, in your own language. The interface now comes in 13 languages besides English, picked in About → Interface language. The timeline now shows how much is moving across the whole video, not only where the peaks are, and ranks the strongest. The player can draw what a detector actually picked out instead of a box around it. And the edit timeline, where a highlight is assembled by dragging, now catches clips that repeat the same footage, has undo, and behaves when you click and press Space.

15 commits on main since 0.13.3.

## Known in this release

- **"Download and install" is not offered yet.** Only a build that carries the release signing key offers it, and this one does not. The update banner still tells you about new versions and opens the download page.
- **Some text is still in English in every language.** Text built from your data as it is shown stays English for now: "Loaded: …", "Video duration: …", most status-bar messages, and the assistant's log lines. So do the "s" and "pts" after numbers in the points panel.
- **The motion curve needs motion run again on a video analysed before this version.** Its cache has no curve, and the motion rows draw exactly as they did. The timeline's Motion button, or a reprocess, fills it in.

## Your language

- **13 interface languages besides English:** Chinese (Simplified), Japanese, Korean, Spanish, Portuguese (Brazil), French, German, Italian, Dutch, Polish, Turkish, Indonesian and Vietnamese. Pick one in About → Interface language; it applies after a restart and is remembered. Whisper's and the subtitles' languages are separate and stay under Transcript.
- **All of the main window and the timeline are covered,** including the points panel, the timeline's row names, its docks (Video Preview, Controls, LLM Assistant), menus, right-click menus and message boxes. The first catalogs left about 260 strings in English in every language; those are now translated.
- **Fixed translations that were plainly wrong.** German saved as "Sparen" (to save money) and exported as "Ausfuhren" (trade exports); Korean called actions "팟캐스트" (podcasts); Turkish named objects "Objects Objects". Entries whose markup a translation had broken, about 120 across the languages, now show the English instead of broken text, and a check keeps new ones from coming in.
- **No more blank buttons.** An empty translation used to blank its widget; Korean's Pause button had no text at all. An empty entry now falls back to English.

## The timeline: how much is moving

- **A motion curve across the whole video,** drawn behind both motion rows. Before, every motion peak was the same orange box, and a barely-there twitch looked like the biggest moment in the video. The curve is how much changed between frames, before any threshold, so ordinary movement draws as a line rather than nothing between spikes. Scene cuts are left out, so a cut does not read as the biggest movement.
- **Peaks are ranked.** Each box is shaded and labelled by its strength ("Peak 9.3×" is 9.3 times the video's average motion), and the five strongest get a dot on the curve and "★1 9.3×". The boxes are still the same draggable boxes, and the curve's outline is drawn over them, so a peak's box no longer hides the top of its own hill.
- **Bars on the timeline have labels again.** On the PySide in the app, a label created with its bar as parent was deleted as soon as it was drawn, so no bar on any row had one.
- **The MOTION EVENTS row has its ◀ ▶ arrows and counter,** stepping between the bars it draws.

## The edit timeline

- **Clips that repeat the same footage are flagged.** When two clips share source time, that footage plays twice in the cut, usually because two signal bars covering the same moment were dragged in. Those clips get an amber band, and after you add one a bar under the timeline asks once: **Merge** (one clip spanning both), **Trim new clip** (cut it down to what no other clip has), or **Keep both** (for a replay; not asked again). "Add all in this row" asks once for the whole batch. Right-click → "Merge with overlapping clip" does it later.
- **Undo.** Ctrl+Z undoes any change to the edit timeline — add, drop, delete, cut, trim, reorder, merge — and Ctrl+Shift+Z or Ctrl+Y redoes, up to 100 steps. A whole "add all in this row" or a merge is one step.
- **Space plays the timeline you are working in.** After clicking a clip in the edit timeline, Space plays the edit from there; after clicking the signal timeline or the main Play, it plays the video.
- **Clicking a clip no longer starts playback.** After Stop, the next click on a clip used to start the edit playing. Clicking now only moves the playhead.
- **The playhead lands in the clip you clicked,** also when two clips overlap; it used to jump to the first clip covering that moment. Play Edit resumes there too.
- **Dragging a clip to the right lands where you drop it.** It used to land one place short, and a clip dragged one place right did not move.

## Outlines and rules

- **Boxes / Outlines in the player.** Next to the Filter button, the overlay can show the outline inside each detection instead of its box. It is for judging a trained model: a box says roughly where, and an outline shows what the model actually picked out, so a wrong detection inside a fair-looking box is easy to see. The choice is remembered.
- **The first outline appears in about 3 seconds, not 30.** Outlines are drawn by SlimSAM, now run through OpenVINO and bundled with the app. Per frame it takes about 210 ms on an Intel Arc and 880 ms on a processor (was 1,360). Outlines on Intel GPUs no longer crash.
- **`compete_with` in composition rules.** When two region classes sit side by side, one object can meet both and both rules fire on it. A rule can now name its neighbour, and an object then counts only for the region it is closest to. On 666 real clips it raised the separation of the easier-to-confuse rule from AUC 0.47 to 0.69 and cut false positives on the neighbour's clips from 45% to 16%. Outlines added at most 0.02 to that, so outlines are for seeing, and `compete_with` is for deciding. YAML only for now; `docs/OUTLINES.md` has the measurements.
- Done for Neva, who asked for outlines; the idea came from Szymek.
