# VideoHighlighter 0.11.1

A small release on the same day as 0.11.0, about the first screen. The app now opens in a one-button Simple view instead of the full set of controls, and the About tab says plainly what Pro adds.

4 commits on main since 0.11.0.

## Known issue: DirectML in the packaged Windows build

The downloaded 0.11.1 exe cannot build the ONNX models DirectML needs: the export fails with `DLL load failed while importing _ml_dtypes_ext`, and detection and action recognition run on the processor. 0.11.2 has the same bug. **It is fixed in 0.11.3.** Installs from source are not affected once `onnxscript` is installed.

## Application and interface

- **Simple view.** The app opens on a single screen: drop a video, pick a highlight length, press Analyze. That run uses a built-in default (motion peaks and loudness bursts) and leaves your detailed settings untouched. The assistant is folded into the same page, so asking why a moment was picked doesn't mean leaving it. **Detailed settings** opens the full workspace as before, and the app remembers which view you used last.
- The About tab describes what Pro actually adds. Face identity, expressions, the report and the assistant are all in this edition; Pro adds teaching the app a vocabulary of your own.

## Fixes

- The Windows installer's fallback config is written as UTF-8 without a byte-order mark, which had broken its JSON parse.
