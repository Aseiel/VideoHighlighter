# VideoHighlighter 0.14.2

The theme of this release is getting the app to you, and out of your way. Downloads now come from a mirror outside GitHub first, which is reachable where GitHub is slow or blocked. Windows Setup speaks your language and no longer downloads what you already have. The Mac download is a third smaller. And the console windows that flashed up during every cut are gone.

10 commits on main since 0.14.1.

## Known in this release

- **Search in other languages is still English-first on Windows.** The model that reads queries in your language is not among the published packs yet, so Setup does not offer it. The macOS build carries it.
- **"Download and install" is not offered yet.** Only a build that carries the release signing key offers it, and this one does not. The update banner still tells you about new versions and opens the download page.

## Downloads

- **A download mirror outside GitHub: [dl.videohighlighter.com](https://dl.videohighlighter.com/downloads/latest/index.html).** Every published release, and the NVIDIA and search-model packs, is copied there, and Setup, the app's own pack downloads and the script installer try it first and GitHub second. Every file is still checked against the SHA-256 recorded when the app was built, whichever host served it. Tested from 10 points on mainland China networks (China Telecom, Unicom, Mobile and Alibaba): the mirror answered all 10, GitHub's download host 7, the other 3 timing out. For mainland China, the link is in the Download section below.
- **0.14.2 is the first build that knows the mirror.** Earlier versions download from GitHub as before; their files are on the mirror too, for anyone who downloads them by hand.

## Windows Setup

- **Setup in your language.** It opens by asking which language to use, preselecting Windows' own, in any of the app's 14 interface languages, and every page after that is in it: Inno Setup's own texts, and this Setup's tasks, download page and messages. The same choice sets the app's language, so the separate language page is gone.
- **Packs already installed are not downloaded again.** Run over an existing install, Setup ticked the visual search model and, with an NVIDIA card, the 1.8 GB NVIDIA pack, and downloaded both again. It now finds each pack, beside the app or in the per-user folder where the app downloads them, and leaves it unticked and marked "already installed". A newer PyTorch is still offered.

## Windows

- **No more console windows during cuts.** Every ffmpeg, ffprobe and yt-dlp the app started flashed up a console window; with ffmpeg from Chocolatey, two per run. Measured from a windowless process like the app: 10 windows for 5 runs before, none now. Run from a terminal, nothing changes.

## Subtitles

- **Make subtitles obeys "Force reprocess (ignore cache)".** It reused the transcript in the cache whatever the box said, so re-transcribing meant deleting the cache. Ticked, it now transcribes again, and says so in the log.

## macOS

- **The DMG is 891 MB, down from 1,375.** The action recognition model (563 MB installed) is now downloaded the first time action recognition needs it, as on Windows, after the app asks. The Mac build ships the pinned pack list and 7-Zip's macOS build to unpack it.
