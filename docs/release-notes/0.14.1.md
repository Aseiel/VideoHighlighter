# VideoHighlighter 0.14.1

The theme of this release is the app working where you are and in what you speak. Choosing an interface language now also sets the language Whisper listens for, the subtitles, narration and search. Subtitles lose Whisper's repetition loops and show lines when they are said. Downloads have a mirror outside GitHub for people GitHub is slow or blocked for, and Hugging Face can point at one too. On a Mac, CLIP, Whisper and action models reach the Apple GPU.

19 commits on main since 0.14.0.

## Known in this release

- **Search in other languages is still English-first on Windows.** The model that reads queries in your language (models-clip-multilingual) is not among the published packs yet, so Windows Setup does not offer it and queries go to CLIP as before. The macOS build carries it.
- **"Download and install" is not offered yet.** Only a build that carries the release signing key offers it, and this one does not. The update banner still tells you about new versions and opens the download page.
- **Subtitles are re-timed only when a video is transcribed again.** A transcript already in the analysis cache loses its repetition loops at once, but moving lines to when they were said needs the audio, so it happens on the next transcription.
- **A short exclamation repeated within a minute is shown once.** Four "Woo!"s a few seconds apart become one; telling those from Whisper's own repeats goes by their shape, not their sound.

## Your language, everywhere

- **The interface language now drives the rest.** Choosing one used to translate the menus and nothing else: Whisper still listened for English, subtitles were written in Polish, narration came back in English, and a Chinese search query was read as English. The transcript and subtitle languages now follow the interface language unless you set them to something else; configs saved before this are moved over once.
- **Narration answers in your language.** Chat models are asked for it; `visualization.narration_language` overrides.
- **Search understands queries in your language** with clip-ViT-B-32-multilingual-v1 (Apache-2.0), which lands in CLIP's own space, so frame indexes stay as they are. On the same test scenes, 3 of 3 found in Chinese, Japanese and Polish, against 1 of 3 before. See *Known in this release* for Windows.
- **The first start asks.** The Windows installer asks which language to use, preselecting Windows' own, and offers the multilingual model when it is not English; elsewhere the app asks, in the language it picked.
- **Japanese and Korean fixes:** "Language" and "Restart required" were mistranslated.

## Subtitles

- **Whisper's repetition loops are gone.** On audio it cannot make out, Whisper locks onto a phrase: one 30-second subtitle saying the same thing fifty times, runs of one-second lines all saying "I'm sorry", or the same short ghost once per window through a pause. A phrase repeated back to back is now said once, a run of three or more identical lines keeps the first, and lines Whisper itself scored as not speech are dropped. On one 72-minute film: 1,574 subtitle lines to 884, and 78 runs of repeated lines to none. Transcripts already analysed are cleaned too, without transcribing again.
- **Lines after a pause appear when they are said.** Whisper starts a line where the previous one ended, so after a quiet stretch it showed up to 23 seconds early. Lines that are far longer than their words take to say are now matched against the audio with Whisper's own aligner, word by word, and take the time their first and last word were said. The words never change, and a line the aligner is not sure of keeps the time it had. In the same film, about 20 lines moved, for under a second of work.
- **Measured and left out:** Whisper's retry at other temperatures (up to 1.85× slower on hard audio, recovers some lines and invents others) and its silence-skip option (5× slower).

## Downloads

- **A download mirror outside GitHub.** GitHub's release downloads are slow or cut off in some places, mainland China above all. Each published release is now copied to Cloudflare, and Setup's downloads (NVIDIA acceleration, the search models), the app's own pack downloads and the script installer try the mirror first and GitHub second. Every file is still checked against the SHA-256 recorded when the app was built, whichever host served it.
- **A Hugging Face mirror, if you choose one.** Models shared on Hugging Face, and weights fetched by name, come from huggingface.co, which is out of reach in some places. `hf_endpoint: https://hf-mirror.com` in `config.yaml` (or `VH_HF_ENDPOINT`) sends them through a mirror you trust. Off unless set.

## macOS

- **CLIP and Whisper on the Apple GPU,** through Metal. Measured on GitHub's M1 machine: CLIP 18-25 ms a frame against 45-57 on the processor, Whisper small about 2.3 s against 3.6 per window.
- **Action models on the Apple GPU,** through Core ML: the frame encoder at 90 ms a frame against 246 on the processor. Its first load compiles for about two and a half minutes; the compiled model is kept in `~/Library/Caches/VideoHighlighter/coreml`, and later loads take about a minute.
- **The GPU is used only once it gives the processor's answer.** On that M1 machine, torch 2.14's Metal returned "ööööö" for a clear sentence and failed CLIP on its first frame, with no error. CLIP and Whisper now compute a fixed input on both and use Metal only when the two agree; otherwise the processor, with the reason in the log. The build pins torch 2.7.1, as on Windows.
- **Metal is used when no compute backend is set,** which is the default; before, CLIP and Whisper never left the processor on a default install.
- **Less memory for object detection:** two workers instead of four, equally fast (6.8 against 6.7 s on the bench), peak 2.2 GB instead of 3.0.
- **A smaller DMG:** 1,495 MB to 1,248 MB before the multilingual search model (+170 MB) was added.
