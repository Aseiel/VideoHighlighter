# VideoHighlighter 0.15.3

<!-- Draft, written from the commit subjects since 0.15.2. Check each line against the app before publishing. -->

The first free build that can update itself. From this release on, About → Updates can download and install a new version in place, fetching only the files that changed. This build has to be installed by hand once, because 0.15.2 and older cannot check the signature of an update.

9 commits on main since 0.15.2.

## Known in this release

- **The shot list uses the simpler detector in this build.** The learned shot-boundary model (TransNetV2) is not downloaded by Setup yet, so cuts are found from frame differences. Running from source with `models/transnetv2/` in place (`tools/export_transnetv2.py` makes it) uses the model.
- **Search in other languages is still English-first on Windows.** The model that reads queries in your language is not among the published packs yet. The macOS build carries it.
- **Updating in place needs an install "for me only".** An install for all users, under Program Files, is offered the download page instead.

## Updates

- **Download and install, in the app.** This build carries the free edition's own release signing key. A release is installed only when its list of files is signed with that key, and each file is checked against its hash before it replaces the old one. If anything fails, the old files are put back.

## Composition rules

- **An event can be any k of its cues.** A rule can now say "two of these four", with some cues marked as required.
- **Rules over MCP.** A model connected over MCP can read, change and apply composition rules.

## Transcript

- **One bad window no longer spoils the next.** Whisper on an Intel GPU decodes the pieces of a film independently.
- **Lines take their words' times**, and a piece that stopped early is read to its end.

## Fixes

- **A long film's shots no longer slow every playback tick** in the timeline viewer.
- **A server that did not answer is not asked again on the GUI thread**, so the window does not freeze waiting for it.
- **A report-only run is logged as completed**, not failed.
- **No more `00-VideoHighlighter-Windows-Setup.zip`** on a release. The Setup.exe is the download.
